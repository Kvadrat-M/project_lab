# Project Lab

Учебный проект для освоения фундаментальных навыков Fullstack-разработки на Python и Django.

## Стек технологий:
- **Язык:** Python 3.12+
- **Контроль версий:** Git и GitHub
- **Изоляция:** Virtualenv (venv)
- **Качество кода:** Ruff и Pylance

## Инструкция по запуску:
1. **Создать виртуальное окружение:**
```bash
python3 -m venv .venv
```
2. **Активировать окружение:**
Для Linux/macOS: 
```bash
source .venv/bin/activate
```
Для Windows: 
```bash
.venv\Scripts\activate
```
3. **Установить зависимости:**
```bash
pip install -r requirements.txt
```
4. **Запустить программу:**
```bash
python engine.py
```
